# Дневник — PWA для подсчёта калорий

Полнофункциональное веб-приложение для отслеживания питания, подсчёта калорий и макронутриентов. Работает офлайн, все данные хранятся локально.

## 🚀 Возможности

### Основные функции
- **Дневник питания** — учёт всех приёмов пищи с навигацией по датам
- **База продуктов** — 120+ продуктов с возможностью поиска и фильтрации
- **Интеграция с Open Food Facts** — поиск продуктов по штрих-коду или названию
- **Конструктор рецептов** — создание рецептов с автоматическим расчётом КБЖУ
- **Статистика** — графики калорий, макронутриентов, динамики веса
- **Челленджи** — система достижений с автоматическим отслеживанием прогресса
- **Образовательные статьи** — 6 статей о питании и здоровье

### Технические возможности
- **PWA** — установка на домашний экран, работа офлайн
- **Сканер штрих-кодов** — через BarcodeDetector API
- **Напоминания** — уведомления о приёмах пищи через Notification API
- **Экспорт/импорт** — CSV и JSON для резервного копирования
- **Тёмная тема** — 6 акцентных цветов + AMOLED режим
- **Адаптивный дизайн** — mobile-first, работает на всех устройствах

## 📱 Страницы приложения

1. **Dashboard** — главная страница с индикаторами калорий, БЖУ, активностью и серией дней
2. **Diary** — дневник питания с навигацией по датам и копированием записей
3. **FoodDatabase** — база продуктов с поиском, фильтрами и интеграцией Open Food Facts
4. **Recipes** — конструктор рецептов с авторасчётом КБЖУ на порцию
5. **Statistics** — аналитика с графиками, экспортом CSV/JSON/PDF
6. **Profile** — настройки профиля с живым расчётом нормы по формуле Миффлина-Сан-Жеора
7. **Scan** — сканер штрих-кодов с камерой и ручным вводом
8. **Challenges** — 4 челленджа с автоматическим расчётом прогресса
9. **Articles** — 6 образовательных статей с модальным чтением
10. **Settings** — настройки темы, единиц измерения, уведомлений, данных

## 📊 Расчёт нормы калорий

Используется формула **Миффлина — Сан-Жеора**:

**Для мужчин:**
```
BMR = 10 × вес(кг) + 6.25 × рост(см) - 5 × возраст(лет) + 5
```

**Для женщин:**
```
BMR = 10 × вес(кг) + 6.25 × рост(см) - 5 × возраст(лет) - 161
```

Затем умножается на коэффициент активности:
- Сидячий образ жизни: 1.2
- Лёгкая активность: 1.375
- Умеренная активность: 1.55
- Высокая активность: 1.725
- Очень высокая: 1.9

Корректировка под цель:
- Похудение: -18%
- Поддержание: 0%
- Набор массы: +12%

## 💾 Хранение данных

Все данные хранятся локально в **localStorage** браузера:
- Профиль пользователя
- Записи дневника
- Продукты и рецепты
- Настройки
- История веса
- Активности

**Важно:** при очистке данных браузера все данные будут удалены. Используйте функцию экспорта JSON для создания резервных копий.

## 🔔 Уведомления

Приложение использует **Notification API** для напоминаний о приёмах пищи. Уведомления работают:
- Когда приложение открыто в браузере
- Когда установлено как PWA на устройство

Для работы уведомлений необходимо разрешить их в настройках браузера.

## 📱 PWA

Приложение можно установить на домашний экран:

**Chrome/Edge:**
- Нажмите иконку установки в адресной строке
- Или: Меню → "Добавить на главный экран"

**Safari (iOS):**
- Нажмите кнопку "Поделиться"
- Выберите "На экран «Домой»"

После установки приложение работает как нативное, с иконкой и полноэкранным режимом.

## 🌐 Open Food Facts

Интеграция с открытой базой продуктов **Open Food Facts** (https://world.openfoodfacts.org/):
- Поиск по названию продукта
- Сканирование штрих-кода
- Автоматическое получение КБЖУ
- Возможность добавить найденный продукт в локальную базу

## 🏆 Челленджи

4 встроенных челленджа:
1. **Серия дней** — вести дневник 7 дней подряд
2. **Калории в цели** — 5 дней из 7 в коридоре ±10% от цели
3. **Белок в норме** — 5 дней из 7 с достаточным белком
4. **Ведение дневника** — 20 дней из 30 с записями

Прогресс рассчитывается автоматически на основе записей дневника.

## 📄 Экспорт данных

Поддерживается экспорт в:
- **CSV** — записи дневника, вес, активность (с русскими заголовками)
- **JSON** — полная резервная копия всех данных
- **PDF** — через функцию печати браузера

## 🔒 Приватность

- Все данные хранятся локально на вашем устройстве
- Никакие данные не отправляются на сервер
- Open Food Facts используется только для поиска продуктов
- Нет аналитики, трекинга или рекламы

### Тестирование и CI

Проект использует **Vitest** + **Testing Library** + **MSW** для тестирования.

- unit-тесты для бизнес-логики (расчёт КБЖУ, утилиты, хранилище)
- интеграционные тесты для Zustand-сторов
- моки API через MSW (Open Food Facts)
- покрытие >60% по всему проекту

CI настроен через GitHub Actions: при каждом push в main и pull_request запускаются тесты и собирается покрытие.
