# Правила работы над техдолгом

## Порядок
- Промпты 1–19 — строго по порядку.
- Не начинать следующий блок, пока предыдущий не закрыт.
- Тесты пишутся в том же промпте, что и код.

## Перед каждым промптом
- Дай CONTEXT-TECHDEBT.md (если новая сессия).
- Дай список файлов для чтения.
- Дай промпт.

## После каждого промпта
- npm run test:run — зелёный.
- npm run test:coverage — покрытие не упало.
- npm run build — зелёный.
- Diff: не тронуты файлы вне скоупа.

## Когда останавливаться
- Тесты падают 2 раза подряд — эскалировать.
- Qwen предлагает переписать существующее — стоп, разобрать отдельно.
- Qwen добавляет новую зависимость без разрешения — отклонить.

## Коммиты
- Один промпт = один коммит.
- Формат: `chore(techdebt): <описание> (#<номер>)`
- Примеры:
  - `chore(techdebt): аудит неиспользуемых зависимостей (#1)`
  - `chore(techdebt): удаление @supabase/supabase-js (#2)`
  - `test: покрытие расчёта КБЖУ (#7)`
  - `feat(storage): миграция на IndexedDB (#12)`
  - `a11y: исправление high-priority проблем (#18)`
