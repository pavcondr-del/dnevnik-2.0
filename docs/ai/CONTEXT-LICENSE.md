# Контекст: удаление MIT-лицензии

## Проект
PWA-трекер питания dnevnik-2.0.
React 18 + TypeScript + Vite + Zustand + Tailwind CSS 4.

## Что делаем
Переводим проект из открытого (MIT) в закрытый коммерческий (проприетарный).

## Причина
ИИ-кодеры по инерции добавляли в файлы заголовки MIT-лицензии.
Владелец проекта не выбирал MIT. Проект планируется как закрытый коммерческий продукт.

## Что нужно
1. Найти ВСЕ вхождения MIT-лицензии и её фрагментов в репо.
2. Удалить их из исходного кода, документации и конфигов.
3. Установить проприетарный статус проекта явно.
4. Проверить, что лицензии сторонних библиотек (React, Zustand и т.д.) НЕ затронуты — они продолжают действовать, но не требуют упоминания в нашем коде.

## Жёсткие правила
1. НЕ удалять лицензии из node_modules и package-lock.json.
2. НЕ трогать лицензии сторонних пакетов в node_modules.
3. НЕ менять copyright-заголовки чужих библиотек.
4. НЕ удалять поле "license" у зависимостей в package.json (это их лицензии).
5. Менять только СВОЙ код и свои конфиги.
6. После каждого шага — тесты должны быть зелёными.
7. Если что-то неоднозначно — уточнять, не угадывать.

- Потом пошаговые действия с командами.
- Потом отчёт: что найдено, что удалено, что осталось.
- В конце — чек-лист DoD.
