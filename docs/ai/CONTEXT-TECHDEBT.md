# Контекст: технический долг dnevnik-2.0

## Что за проект
PWA-трекер питания на React 18 + TypeScript + Vite + Zustand + Tailwind CSS 4 + Framer Motion.
Сборка через vite-plugin-singlefile в один HTML.
Все данные хранятся локально. Никаких внешних API, кроме Open Food Facts (опционально).

## Что делаем сейчас
Закрываем технический долг:
1. Внедряем тесты (Vitest + RTL + MSW).
2. Удаляем неиспользуемые зависимости.
3. Мигрируем localStorage → IndexedDB.
4. Расширяем объём хранимых данных.
5. Добавляем доступность (a11y).

## Правила
1. Никаких новых зависимостей, кроме явно указанных в промпте.
2. Существующий код не ломать — только добавлять и аккуратно рефакторить.
3. Стили — только Tailwind-токены проекта.
4. Тесты — Vitest + @testing-library/react + jsdom + msw.
5. Покрытие новых файлов ≥ 70%. Для чистой логики — 100%.
6. Перед задачей — прочитать связанные файлы в репо.
7. После задачи — `npm run test:run` зелёный, `npm run test:coverage` не упал.
8. Никаких console.log, TODO, «пока так» в финальном коде.
9. Если задача неоднозначна — уточнить, не угадывать.
10. Один промпт = один коммит.

## Как отвечать
- Сначала план (3–5 пунктов).
- Потом код с путями файлов.
- Потом тесты.
- В конце — чек-лист DoD с отметками.
