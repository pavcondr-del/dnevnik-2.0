# Аудит доступности (a11y) — dnevnik-2.0

**Дата:** 2024-09-19  
**Инструменты:** axe-core, ручная проверка клавиатурной навигации  
**Статус:** 🔴 Требуются исправления

---

## Методология

1. Автоматическая проверка через axe-core (в тестах)
2. Ручная проверка навигации с клавиатуры (Tab, Enter, Escape, стрелки)
3. Проверка контраста цветов через DevTools
4. Тестирование со скринридером (NVDA/VoiceOver) — запланировано

---

## Найденные проблемы

### 🔴 High priority (критичные)

| # | Компонент | Проблема |Impact | Решение | Статус |
|---|-----------|----------|--------|---------|--------|
| H1 | `Modal.tsx` (ui.tsx) | Нет фокус-трапа внутри модального окна | Фокус уходит за пределы модалки | Реализовать фокус-трап с возвратом на триггер | ⏳ Ожидает |
| H2 | Кнопки с иконками (`Notes.tsx`, `Meals.tsx`, `FoodDatabase.tsx`) | Кнопки только с иконками без `aria-label` | Непонятно назначение кнопки для скринридеров | Добавить `aria-label` для icon-only кнопок | ✅ Частично исправлено |
| H3 | Формы (`Calculators.tsx`, `Dashboard.tsx`, `Profile.tsx`, `BackupManager.tsx`) | `<label>` не связаны с `<input>` через `htmlFor`/`id` | Скринридеры не объявляют поле при фокусе | Связать label htmlFor={input.id} | ⏳ Ожидает |
| H4 | `Ring.tsx`, `MiniRing` | Прогресс-кольца без `role="progressbar"`, `aria-valuenow/min/max` | Непонятен прогресс для скринридеров | Добавить aria-атрибуты | ⏳ Ожидает |
| H5 | `Toast.tsx` (ui.tsx) | Есть `role="status"` и `aria-live`, но проверить все уведомления | Уведомления могут не объявляться | Проверить все точки показа тостов | ✅ Уже реализовано |
| H6 | Все страницы | Не виден фокус при навигации Tab | Невозможно понять текущий элемент | Добавить `:focus-visible` стили | ⏳ Ожидает |
| H7 | `Diary.tsx` | Навигация по датам: кнопки «←» и «→» без явных `aria-label` | Недоступно с клавиатуры | Добавить уникальные aria-label | ⏳ Ожидает |
| H8 | Все страницы | Отсутствует skip-link для перехода к основному контенту | Пользователи клавиатуры вынуждены проходить всю навигацию | Добавить ссылку «Перейти к содержанию» в начале страницы | ⏳ Ожидает |

## Как проверять

### Автоматически (axe-core)
```bash
npm run test:a11y  # требует установки axe-core
```

### Вручную
1. **Клавиатура**: Tab, Shift+Tab, Enter, Escape, стрелки
2. **Скринридер**: NVDA (Windows), VoiceOver (macOS)
3. **Контраст**: DevTools → Rendering → Emulate vision deficiencies
