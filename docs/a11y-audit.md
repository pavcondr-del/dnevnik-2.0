# Аудит доступности (a11y) — dnevnik-2.0

**Дата:** 2024-09-19  
**Инструменты:** axe-core, ручная проверка клавиатурной навигации  
**Статус:** 🔴 Требуются исправления

---

## Методология

1. Автоматическая проверка через axe-core (в тестах)
2. Ручная проверка навигации с клавиатуры (Tab, Enter, Escape, стрелки)
3. Проверка контраста цветов через DevTools
4. Тестирование со скринридером (NVDA/VoiceOver) — запланировано

---

## Найденные проблемы

### 🔴 High priority (критичные)

| # | Компонент | Проблема |Impact | Решение |
|---|-----------|----------|--------|---------|
| H1 | `Modal.tsx` | Нет `role="dialog"`, `aria-modal`, фокус-трапа | Скринридеры не объявляют модалку, фокус уходит за пределы | Добавить aria-атрибуты, реализовать фокус-трап |
| H2 | `Button.tsx` | Кнопки с иконками без `aria-label` | Непонятно назначение кнопки для скринридеров | Добавить `aria-label` для icon-only кнопок |
| H3 | Формы (Profile, Settings) | `<label>` не связаны с `<input>` через `htmlFor` | Скринридеры не объявляют поле при фокусе | Связать label htmlFor={input.id} |
| H4 | `ProgressBar.tsx` | Нет `role="progressbar"`, `aria-valuenow/min/max` | Непонятен прогресс для скринридеров | Добавить aria-атрибуты |
| H5 | `Toast.tsx` | Нет `role="status"`, `aria-live` | Уведомления не объявляются | Добавить `aria-live="polite"` |
| H6 | Все страницы | Не виден фокус при навигации Tab | Невозможно понять текущий элемент | Добавить `:focus-visible` стили |
| H7 | `Diary.tsx` | Навигация по датам только мышью | Недоступно с клавиатуры | Добавить обработчики Enter/стрелок |

### 🟡 Medium priority (средние)

| # | Компонент | Проблема | Решение |
|---|-----------|----------|---------|
| M1 | `Charts.tsx` | Графики без текстового описания | Добавить `<caption>` или `aria-describedby` |
| M2 | `FoodDatabase.tsx` | Поиск без `aria-label` на input | Добавить label или aria-label |
| M3 | `Navigation.tsx` | Порядок Tab нелогичный на мобильных | Пересмотреть порядок в DOM |
| M4 | Все изображения | Некоторые `<img>` без `alt` | Добавить alt="" для декоративных, описательный для контентных |
| M5 | `Settings.tsx` | Переключатели тем без aria-pressed | Добавить `aria-pressed` для toggle-кнопок |

### 🟢 Low priority (низкие)

| # | Компонент | Проблема | Решение |
|---|-----------|----------|---------|
| L1 | Контраст цветов | Некоторые акцентные цвета < 4.5:1 на светлом фоне | Заменить на более контрастные токены Tailwind |
| L2 | `Articles.tsx` | Длинные статьи без якорей | Добавить навигацию по заголовкам |
| L3 | `Scan.tsx` | Сканер штрих-кодов без альтернативы | Убедиться, что ручной ввод доступен |

## Как проверять

### Автоматически (axe-core)
```bash
npm run test:a11y  # требует установки axe-core
```

### Вручную
1. **Клавиатура**: Tab, Shift+Tab, Enter, Escape, стрелки
2. **Скринридер**: NVDA (Windows), VoiceOver (macOS)
3. **Контраст**: DevTools → Rendering → Emulate vision deficiencies
