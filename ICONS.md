# Калорийка — PWA иконки

## SVG иконки (готовы к использованию)

Все SVG иконки уже созданы и работают в современных браузерах:

- `icon-192.svg` — 192x192 (стандартная)
- `icon-512.svg` — 512x512 (стандартная)
- `icon-maskable.svg` — 512x512 (maskable, с safe zone padding)

## Генерация PNG иконок (опционально)

Если нужны PNG версии для максимальной совместимости:

### 1. Установите sharp:
```bash
npm install --save-dev sharp
```

### 2. Запустите скрипт генерации:
```bash
node generate-icons.js
```

Скрипт создаст:
- `icon-192.png` (192x192)
- `icon-512.png` (512x512)
- `icon-maskable.png` (512x512, maskable)

### 3. Пересоберите проект:
```bash
npm run build
```

## Maskable иконка

Maskable иконка создана с padding (иконка занимает ~70% размера), чтобы обеспечить safe zone для различных форм обрезки на разных устройствах.

## Поддержка браузеров

- **SVG иконки**: Chrome 96+, Edge 96+, Firefox 111+, Safari 16.4+
- **PNG иконки**: Все браузеры (для обратной совместимости)

Manifest настроен на использование обоих форматов для максимальной совместимости.
